# API Bancária com FastAPI 💳

Projeto desenvolvido para simular operações bancárias com autenticação JWT.

## 🚀 Funcionalidades
- Cadastro de usuário
- Login com JWT
- Criação de conta
- Depósito
- Saque
- Extrato

## 🛠️ Tecnologias
- FastAPI
- SQLAlchemy
- JWT
- SQLite

## ▶️ Como rodar

```bash
pip install -r requirements.txt
python -m uvicorn src.main:app --reload
```

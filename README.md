## Sobre o projeto

Este projeto tem como objetivo documentar minha evolução no aprendizado em tecnologia, organizando os principais desafios realizados durante o programa da DIO em parceria com o LuizaLab.

Aqui estão reunidos conceitos, práticas e projetos que ajudaram a desenvolver minha base como futura profissional da área de tecnologia.

## O que foi aprendido

### Lógica de Programação

* Análise e compreensão de problemas
* Criação de soluções passo a passo
* Interpretação de erros e correções
* Uso da IA como apoio no aprendizado (sem substituir o raciocínio)

---

### Inteligência Artificial aplicada ao estudo

* Uso de IA como ferramenta de aprendizado ativo
* Organização de conhecimento com curadoria de fontes
* Pensamento crítico na validação de respostas
* Estruturação de conteúdos em formato de estudo

---

### GitHub e organização de projetos

* Criação e organização de repositórios
* Versionamento de código
* Estruturação de README profissional
* Importância da documentação clara

### Programação Orientada a Objetos (POO)

* Criação de classes e objetos
* Encapsulamento de dados
* Estruturação de sistemas reais (banco)

* Evolução de estruturas simples para modelos orientados a objetos
